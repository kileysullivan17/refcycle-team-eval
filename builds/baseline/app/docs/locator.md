# Recycling center locator

**Server.** `GET /api/sites?place=<id>[&rule_ids=a,b][&material=<value>]` (`src/features/locator/sites.ts`). It loads the packs with the engine's `loadPacks` and `engine/data/facilities.csv`, drops `internal_notes`, maps `type` to `kind`, turns "withheld" and "not listed" addresses into `null`, gives pins only to site and event records that have coordinates, and adds `event_last_date` for the four Hawaiʻi County events. Without `rule_ids` it returns every linked record for the place; with them, the records linked to those rules, with `only_site` when a location-limited rule links there. Sorted by name. Rules from `superseded` sources are never read. A load failure returns 500 `{ "error": "Site data could not be loaded" }` and logs the detail on the server.

**Screens.** `/locations` has Map and List views, a material filter, and an item mode opened by Dispose (`?item=&rule_ids=`). The map uses bundled Leaflet 1.9.4 and OpenStreetMap tiles with the visible attribution; records without a pin appear only in the list. Each card shows the address if sourced, the CSV notes (fees, appointments, limits), "only place" for location-limited rules, field observation or report notes with dates, the source link and date checked. Events say "Tentative" until their last date and "Check the source for the next event" after it. When the cited rules name no place the screen says so and links the official source. `/locations/:id` lists the items its rules send there. No device location, distances, hours, phone numbers or ratings.

For a conditional answer the Dispose link carries each case as a `case=<stream>|<if>` parameter; the list groups by case, and only cases ending in a special drop-off or deposit return list sites (decision D1).
